# ADR-001: Use Laravel 12

Status: Accepted

## Context

The project requires a modern PHP framework with strong community support, long-term maintainability, security features, and rapid development capabilities.

## Decision

Laravel 12 will be used as the primary backend framework.

## Alternatives Considered

- Symfony
- CodeIgniter
- Yii
- Plain PHP

## Rationale

Laravel provides:

- Elegant syntax
- Eloquent ORM
- Queue system
- Authentication
- Authorization
- Strong ecosystem
- Excellent documentation

## Consequences

Positive:

- Faster development
- Large community
- Long-term support
- Rich package ecosystem

Negative:

- Slightly higher resource usage than micro-frameworks.
