# New developer? Start here.

This repository's **source-specific developer documentation** is under [`docs/07_DEVELOPER_ONBOARDING/`](docs/07_DEVELOPER_ONBOARDING/).

**Best reading order:**

1. [`01_DEVELOPER_HANDBOOK.md`](docs/07_DEVELOPER_ONBOARDING/01_DEVELOPER_HANDBOOK.md) — project architecture, modules, ownership and where to make changes.
2. [`04_WORKFLOW_AND_DATA_MAP.md`](docs/07_DEVELOPER_ONBOARDING/04_WORKFLOW_AND_DATA_MAP.md) — complete question → blueprint → exam → result lifecycle with Mermaid diagrams.
3. [`05_ROUTES_AND_PERMISSIONS.md`](docs/07_DEVELOPER_ONBOARDING/05_ROUTES_AND_PERMISSIONS.md) — URL/route index, eight user roles, authorization and tenant checks.
4. [`06_SETUP_TEST_AND_TROUBLESHOOT.md`](docs/07_DEVELOPER_ONBOARDING/06_SETUP_TEST_AND_TROUBLESHOOT.md) — Windows/XAMPP installation, database, seed, testing and debugging.
5. [`07_NEW_DEVELOPER_TASKS.md`](docs/07_DEVELOPER_ONBOARDING/07_NEW_DEVELOPER_TASKS.md) — sample developer tasks, change checklist and pitfalls.
6. [`08_SCHEMA_REFERENCE.md`](docs/07_DEVELOPER_ONBOARDING/08_SCHEMA_REFERENCE.md) — tables, relations, migration constraints and ERD.
7. [`03_SOURCE_FILE_INDEX.md`](docs/07_DEVELOPER_ONBOARDING/03_SOURCE_FILE_INDEX.md) — **all 555 original files**, grouped, described and tagged if empty.
8. [`02_COMPLETE_FILE_TREE.txt`](docs/07_DEVELOPER_ONBOARDING/02_COMPLETE_FILE_TREE.txt) — literal original source directory tree.

The developer pack is **documentation only**; the application PHP, Blade and JS logic is not altered by this addition. Read [`FIXES_AND_VERIFICATION.md`](FIXES_AND_VERIFICATION.md) for existing review limitations; the complete Laravel runtime and browser acceptance testing have not been proven in this environment.
